# Data

`subjects_info.csv` is the rows for the recordings used here, copied from the **Pulse Transit Time PPG Dataset**
(version 1.1.0, `csv/subjects_info.csv`): Mehrgardt, P., Khushi, M., Poon, S., & Withana, A. (2022), PhysioNet,
https://doi.org/10.13026/jpan-6n92. Licence: Open Data Commons Open Database License v1.0.
Blood pressure and heart rate in this file were measured with an OMRON HEM-7322 cuff monitor at the start and end of
each recording. (Use version 1.1.0: version 1.0.0 had the diastolic columns duplicated from the systolic ones.)

The 500 Hz waveform files (`s10_sit.csv` etc., about 40 MB each) are NOT included here. Download them from
https://www.physionet.org/content/pulse-transit-time-ppg/1.1.0/csv/ into a folder and pass it to the scripts.
